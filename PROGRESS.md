# Progress

How much of `RRR.EXE` (the race) is rebuilt from C. Generated by `reverse-engineering/tools/progress.py`
(do not edit by hand), measured at commit `2e1eb73`.

**129 of the 147 functions known in the game's own C compile to the original's exact bytes (87.8%).**

Of RRR.EXE's code object after `BEGTEXT` (201,760 bytes), 60,134 bytes (29.8%) are rebuilt byte for byte or identified as byte-identical Watcom library code.

A function counts only when our build of `src/` (Watcom C/C++ 10.5, `-3r -s -ox`) gives
the same bytes as the game at the same address, with every address it refers to checked as
well. A near miss compiles but its code still differs: the number is how many instructions
differ (`reverse-engineering/tools/wc/fndiff.py`). The list of functions not written yet comes
from a recursive-descent scan that finds about 60% of the code, so the total will grow.

To search and filter the functions and see each near miss's diff, open
[`docs/RRRPROGRESS.HTML`](docs/RRRPROGRESS.HTML) in a browser.
